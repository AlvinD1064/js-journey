## Overview
This folder contains small JavaScript programs built while learning string manipulation.

The goal is to understand how to clean, transform, and format text using built-in string methods.

## What I practiced
- Removing extra spaces using trim() and replace()
- Changing text casing (lowercase, uppercase, sentence case)
- Extracting and combining parts of strings using slice() and charAt()
- Formatting raw input into readable output


## Key Learning
- Strings are immutable, so every transformation creates a new value
- Small transformations can be chained to solve real formatting problems
